# 路线图

## 0.3 版本方向调整

0.3 的核心方向调整为“按盘符和目录树调查空间变化”：

- 普通目录实时监控默认开启。
- 噪音目录只做间隔快照，默认 3 分钟一次。
- 重点监控名单支持手动添加可疑目录，默认 1 分钟快照、8 层深度、独立日志。
- GUI 增加磁盘、目录树、噪音目录、重点监控等页面。
- 后续继续补强：重点监控暂停/过期状态、噪音目录完整编辑器、目录树历史趋势图、按盘符的快速增长提醒视图。

## 0.1 版本

- 创建标准项目骨架。
- 实现桌面界面。
- 接入 SQLite 本地数据库。
- 提供默认监控规则和隐私模式。
- 支持目录快照扫描。
- 支持基础 `watchdog` 文件事件记录。
- 增加中英文界面切换，默认中文。
- 增加目录占用排行、变化时间线、来源占比、活动热力图。
- 增加调查视图：最近 30 分钟、2 小时、今天、7 天的快照对比。
- 在 GUI 中启动和停止实时监听，并自动刷新界面。
- 增加后台记录模式和当前用户登录后自动启动选项。
- 增加按日期分类的可提取日志，方便交给 AI 或人工分析。
- 增加短时间增长阈值提醒，并写入提醒日志。
- 排除日志目录，避免工具记录自己生成的日志。
- 在 GUI 设置页编辑日志目录、提醒窗口、提醒阈值和后台快照间隔。
- 在 GUI 设置页编辑监控规则。
- 调查页支持用户自定义起止时间范围。
- 调查页支持目录钻取，查看监控目录下一层子项的当前大小排行。
- 导出调查报告，并支持隐藏常见私人路径。
- 改进快速开始文档，让新手知道每条命令的作用。
- 编写自动化测试。

## 未来的 C++ / Windows 原生模块

只有在 Python 版本已经验证产品逻辑后，才考虑加入 C++ 或其他原生模块。

可能目标：

- 支持 NTFS USN Journal。
- 在大型目录树上提升性能。
- 提高底层文件变化追踪的准确性。
