# 路线图

## 0.1 版本

- 创建标准项目骨架。
- 实现桌面界面。
- 接入 SQLite 本地数据库。
- 提供默认监控规则和隐私模式。
- 支持目录快照扫描。
- 支持基础 `watchdog` 文件事件记录。
- 增加中英文界面切换，默认中文。
- 增加目录占用排行、变化时间线、来源占比、活动热力图。
- 增加调查视图：最近 30 分钟、2 小时、今天、7 天的快照对比。
- 在 GUI 中启动和停止实时监听，并自动刷新界面。
- 增加后台记录模式和当前用户登录后自动启动选项。
- 增加按日期分类的可提取日志，方便交给 AI 或人工分析。
- 增加短时间增长阈值提醒，并写入提醒日志。
- 排除日志目录，避免工具记录自己生成的日志。
- 在 GUI 设置页编辑日志目录、提醒窗口、提醒阈值和后台快照间隔。
- 改进快速开始文档，让新手知道每条命令的作用。
- 编写自动化测试。

## 0.2 版本

- 在界面里编辑监控规则。
- 支持用户自定义扫描频率。
- 增强调査窗口，例如自定义时间范围。
- 支持目录钻取，查看某个大目录下面哪些子目录增长最多。
- 导出调查报告，并支持隐藏私人路径。

## 0.3 版本

- 增加后台托盘模式。
- 改进事件合并和降噪能力。
- 考虑可选数据库加密。
- 改进长期运行的性能和数据库体积控制。

## 未来的 C++ / Windows 原生模块

只有在 Python 版本已经验证产品逻辑后，才考虑加入 C++ 或其他原生模块。

可能目标：

- 支持 NTFS USN Journal。
- 在大型目录树上提升性能。
- 提高底层文件变化追踪的准确性。
